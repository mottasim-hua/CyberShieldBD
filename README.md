CyberShield BD
AI-Based Phishing & Scam Detection System
-Developed a machine learning-based application to detect phishing URLs and spam messages, providing risk scores and explainable predictions.
-Implemented URL feature extraction and text processing to analyze suspicious links and messages.
-Integrated a Flask web interface to display prediction results, risk scores, and explanations.
Technologies used: Python, Flask, Scikit-learn, XGBoost, Pandas, NumPy, HTML, CSS, JavaScript.
